## 🚀 Flagship Architectural Registry

### 🛍️ OmniMart — Interactive 3D/Canvas E-Commerce Platform
> A hyper-fast, high-performance interactive digital store built with a 60fps Scroll-Driven Canvas Engine.
* **Architecture:** Formulated with React 18+ strictly typed in TypeScript, Tailwind CSS v4 design system, and Zustand state stores with LocalStorage matrix synchronization.
* **Engine & Security:** Powered by an HTML5 `<canvas>` frame scrubbing engine (60fps), resilient offline graceful fallbacks, Firebase JWT authentication, and cloud-enforced Firestore security rules.

### 🌙 Sukna (سُكنى) — Islamic Web-to-Native Platform
> A zero-dependency, high-comfort Islamic Web-to-Native workspace for Quranic reading, audio streaming, and daily worship.
* **Architecture:** Engineered with Vanilla JS (ES6+), HTML5, and Tailwind CSS. Features custom zero-latency LocalStorage state management and optimized mobile WebView mechanics.
* **Hardware Interfacing:** Integrates real-time geolocation spherical trigonometry for accurate Qibla direction alignment and native browser Haptic Feedback for interactive digital Tasbih.

### 🤖 ProfileReady — AI Career Automation Suite
> An AI-powered SaaS builder optimized for generating dynamic, ATS-compliant professional resumes and career assets.
* **Architecture:** Multi-AI pipeline powered by Grok API and Gemini API integrations. Automatically structures non-standard user inputs into high-scoring recruitment models.

### 🎓 Sit El-Kol (سِتّ الكل) — University Academic Hub
> An integrated, multi-semester learning management system and exam simulator engineered for university cohorts.
* **Architecture:** Formulated with real-time Firebase Authentication, Cloud Firestore databases, dynamic term-based UI adaptation, and client-side password-protected control panels.

### 💰 Felosak Fein — Personal Budget & Expense Planner
> Interactive daily expense planner and budget distribution system.
* **Architecture:** Integrated with Firebase Cloud Firestore for real-time personalized financial tracking and salary allocation planning.

### 🧪 T3lemk (تعلمك) — Middle School EdTech Platform
> Modular educational engine designed specifically for middle school curriculums.
* **Architecture:** Built with modular ES6+ JavaScript, fully secured via server-side Firestore rules on Vercel.
