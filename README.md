## 🚀 Architectural Project Registry

### 📁 Core Production Platforms

#### 🛍️ OmniMart Platform — Interactive 3D/Canvas E-Commerce Architecture
> A hyper-fast, high-performance interactive digital store built with a 60fps Scroll-Driven Canvas Engine.
*   **Architecture:** Formulated with React 18+ strictly typed in TypeScript, Tailwind CSS v4 design system, and Zustand state stores with LocalStorage matrix synchronization.
*   **Engine & Security:** Powered by an HTML5 `<canvas>` frame scrubbing engine (60fps), resilient offline graceful fallbacks, Firebase JWT authentication, and cloud-enforced Firestore security rules.

#### 🌙 Sokna Platform (سُكنى للقرآن الكريم)
> A zero-dependency, high-comfort Islamic Web-to-Native workspace for Quranic reading, audio streaming, and daily worship.
*   **Architecture:** Engineered with Vanilla JS (ES6+), HTML5, and Tailwind CSS. Features custom zero-latency LocalStorage state management and optimized mobile WebView mechanics.
*   **Hardware Interfacing:** Integrates real-time geolocation spherical trigonometry for accurate Qibla direction alignment and native browser Haptic Feedback for interactive digital Tasbih.

#### 🤖 ProfileReady (`profile-ready.vercel.app`)
> An AI-powered SaaS builder optimized for compiling dynamic, ATS-friendly professional resumes and career assets.
*   **Architecture:** Multi-AI pipeline powered by Grok API and Gemini API integrations. Seamlessly maps user data into highly structural CV models designed to maximize passing scores in automated recruitment algorithms.

#### 🎓 Sit El-Kol Platform (`set-el-kol.vercel.app`)
> An integrated, multi-semester learning management system and exam simulator engineered for university cohorts.
*   **Architecture:** Formulated with real-time Firebase Authentication, Cloud Firestore database instances, dynamic term-based UI adaptation, and client-side password-protected control panels.

#### 🧪 T3lemk Platform (`t3lemk.vercel.app`)
> A comprehensive EdTech application structured specifically for middle school curriculums.
*   **Architecture:** Engineered utilizing modular ES6+ JavaScript and fully secured via server-side Firestore rules on Vercel.

#### 💰 Felosak Fein (`expenses-tracker-beta-plum.vercel.app`)
> An interactive daily expense planner and budget distribution tracker.
*   **Architecture:** Integrated directly with Firebase database systems, enabling personalized user financial planning and active salary planning tools.

#### 🌐 Live Portfolio Hub (`portfolio-nu-nine-71.vercel.app`)
> The production-grade engine powering this showcase.
*   **Architecture:** Multi-theme personal portfolio website designed to showcase operational production platforms and optimized asset delivery pipelines.
